# 奶龙 2048

一个以“奶龙”主题包装的 2048 合成小游戏。本仓库当前处于规划阶段，默认交付目标是与“奶蛙工厂”示例相同的 H5 网页小游戏：打开 GitHub Pages 链接即可玩，在手机与桌面浏览器上共用一套代码。

> 版权提醒：奶龙角色、名称、形象、音频等可能涉及知识产权。公开发布或商业化前必须取得相应授权；研发阶段应使用自制占位素材，且素材来源要留档。

## 第一版目标

- 标准 4×4、2/4 随机生成、滑动合并与计分
- 键盘、触屏滑动、重新开始、撤销一步
- 当前分与历史最高分本地保存
- 胜利、失败、继续游戏流程
- 奶龙主题视觉、基础音效及静音控制
- 响应式布局、基础无障碍、离线可玩
- GitHub Pages 自动发布，手机可“添加到主屏幕”
- 核心逻辑单元测试与主要流程端到端测试

## 暂不纳入 MVP

- 登录、云存档、排行榜、支付、广告
- 多人对战、活动系统、复杂皮肤商城
- 原生 App 安装包

这些功能应在验证留存和授权条件后再进入第二阶段。

## 本地运行

需要 Node.js 22 或更高版本：

```bash
npm install
npm run dev
```

终端会显示本机访问地址。同一 Wi-Fi 下的手机可以打开 `Network` 地址试玩。

## 验证与构建

```bash
npm test
npm run typecheck
npm run build
npm run preview
```

生产文件生成在 `dist/`。规则测试覆盖连续合并、空位压缩、无效移动、随机生成和失败判定。

## 发布到 GitHub Pages

1. 将仓库推送到 GitHub，并确保默认分支名为 `main`。
2. 在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。
3. 推送代码后，`.github/workflows/deploy.yml` 会自动执行测试、构建并发布。
4. 发布地址通常为 `https://<用户名>.github.io/<仓库名>/`。

Vite 使用相对资源路径，因此部署在 GitHub Pages 的项目子目录时无需手动修改仓库名。
